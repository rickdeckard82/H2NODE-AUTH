# A10 Networks ACOS (Thunder / Thunder CGN) — apontar para o Pulse RADIUS

Cobre os appliances **Thunder CGN** (CGNAT) — ex.: **CGN 1040** e **CGN 4440** —
e demais plataformas ACOS (ADC/CFW). `10.0.0.254` = IP do host que roda o
container `freeradius`.

```
radius-server host 10.0.0.254 secret <shared-secret-cadastrado-no-painel>
authentication type radius local
```

> No ACOS o `authentication type` é global. `radius local` tenta o RADIUS e cai
> para o usuário local se o servidor não responder.

## Autorização

O perfil de privilégio no painel deve conter, para o fabricante **A10 Networks**:

| Atributo (fabricante A10 no painel) | Valor de referência |
|---|---|
| `A10-Admin-Privilege` | `3` (Root / read-write total) / `12` (partição enable-disable) / `14` (Read-Only) |

Para restringir o admin a uma partição L3V, some `A10-Admin-Partition = <nome>`
ao perfil. Os números de `A10-Admin-Privilege` **variam entre releases do
ACOS** — confirme com o guia *Management Access* / *System Configuration and
Administration* da sua versão. Como nos demais fabricantes, dá para editar a
linha do fabricante A10 no editor de perfis sem tocar no FreeRADIUS; o
`radius/dictionary.local` embarca uma definição de referência
(`VENDOR A10 22610`, `A10-Admin-Privilege` inteiro).

## Contabilização de comandos

Habilite o *command accounting* apontando para o Pulse e, no
`radius/sites-available/default` (bloco `accounting`), mapeie o VSA de comando
do seu firmware para `Pulse-Command` — confirme o nome exato com
`freeradius -X` num comando real. Ver `docs/RUNBOOK.md`.

## TACACS+ (alternativa ao RADIUS)

No painel: grupo **A10 Networks** → *Protocolo AAA* = `tacacs` + *Chave
TACACS+*. No ACOS:

```
tacacs-server host 10.0.0.254 secret <chave-cadastrada>
authentication type tacplus local

authorization commands 15 default tacplus local
accounting exec default start-stop tacplus
accounting commands 15 default start-stop tacplus
```

O `priv-lvl` do perfil vira o nível de acesso (15 = read-write, ≤14 =
read-only); os comandos executados aparecem nas telas **Authorization** e
**Accounting** do painel.
